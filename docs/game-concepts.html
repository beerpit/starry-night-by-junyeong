1잃어버린 열한 개의 별

포인트 앤 클릭 어드벤처 + 수수께끼웹 · 태블릿 최적

“소용돌이 바람이 밤하늘의 별 열한 개를 마을에 흩뿌렸어요. 꼬마 화가가 붓을 들고 그림 속으로 들어가 별을 다시 하늘에 걸어 주세요!”

목업: 아이 그림을 확대해 장면 배경으로 쓰고, 노란 점선이 눌러 볼 수 있는 곳(핫스폿), 아래는 가방, 오른쪽 위 반딧불이 힌트(퍼즐의 「찬스」와 같은 제한형).

게임 루프

장면 둘러보기→핫스폿 누르기·대화→물건 얻기→물건 쓰기 / 수수께끼 풀기→별 되찾기 ★→하늘에 걸기(퍼즐 미니게임)↻

장면과 수수께끼 — 모두 그림 속 실제 장소

장면그림 속 장소수수께끼(유형)얻는 것
1사이프러스 나무 아래나무 그림자 속 숨은 별 3개 찾기(숨은 그림) · 부엉이에게 길 묻기(대화 선택)별 3, 붓
2마을 골목창문 불을 「아빠 집 → 빵집 → 학교」 순서로 켜기(순서 기억) · 물감 방울로 문패 색 맞추기별 2, 사다리
3교회 첨탑종 세 개 소리 높낮이 따라 치기(소리 패턴) · 사다리 쓰기별 2, 등불
4소용돌이 언덕바람 길 타일을 돌려 별을 굴려 보내기(회전 타일 퍼즐)별 2
5달의 집되찾은 별로 별자리 잇기(점 잇기) → 하늘 완성 연출별 2, 엔딩

설계 포인트

  • 막다른 길 없음: 실패 상태가 없고, 반딧불 힌트(장면마다 2개, 다 쓰면 1분 뒤 1개 충전)로 반드시 진행.
  • 읽기 부담 최소: 대사는 2줄 이하 + 그림 아이콘, 선택적 음성(부모 녹음 기능 — 「아빠 목소리로 읽어 주기」).
  • 아이 그림을 층으로: 사이프러스·마을·언덕·하늘을 분리(퍼즐 게임의 분할 방식 응용 + 수작업 보정)해 시차 스크롤로 깊이감.
  • 마지막 장면 = 퍼즐 게임 연결: 되찾은 별을 끌어다 하늘에 거는 미니 퍼즐(현 엔진의 조각·붙임 재사용).

2바람을 타는 반딧불

횡스크롤 원버튼 아케이드휴대폰 세로·가로 모두

“누르고 있으면 떠오르고, 떼면 내려가요. 고흐의 소용돌이 바람을 타고 별가루를 모아 달까지 날아가요!”

게임 루프

누르기/떼기로 높이 조절→소용돌이 바람 타기(가속·곡선)→별가루 모으기·먹구름 피하기→체크포인트 별→달 도착 · 별점↻

규칙

  • 한 가지 조작: 화면 아무 곳 누르기(스페이스바·게임패드 A 도 가능). 어린아이도 바로 이해.
  • 게임 오버 없음: 먹구름·부엉이에 닿으면 별가루 일부를 떨어뜨리고 잠깐 깜빡일 뿐. 바닥에 닿으면 튕겨 오름.
  • 소용돌이: 바람장 안에 들어가면 회전 방향으로 끌려가며 빨라짐 — 잘 타면 큰 보너스 「바람 서핑」.
  • 별점: 모은 별가루 비율로 ★1~3, 구간별 최고 기록. 매일 바뀌는 「오늘의 하늘」(날짜 시드).

구간

구간배경(그림의 띠)새 요소
1 마을 위지붕·창문 불빛기본 조작, 별가루 줄
2 사이프러스 숲검은 나무 실루엣(앞 층)좁은 틈 통과
3 소용돌이 하늘흰·파란 소용돌이바람장(가속·곡선)
4 별 무리노란 별 원들별에 닿으면 튕기는 범퍼
5 달초승달짧은 마무리 + 퍼즐 조각 보상

기술 스케치

// 고정 시간 간격(1/120초) 물리 — 기기 성능과 무관하게 같은 궤적
vy += (pressed ? -LIFT : GRAVITY) * dt;
// 소용돌이 = 와류 합: 각 중심 c, 세기 k, 반경 r
for (v of vortices) { d = pos - v.c; f = v.k * exp(-|d|²/v.r²); vel += perp(d) * f * dt; }
// 레벨 = 시드 기반 생성: 구간마다 별가루 곡선(사인 합) + 장애물 간격 규칙
// 배경 = 아이 그림을 가로로 이어 붙인 띠(좌우 반전으로 이음매 숨김) + 3층 시차
  • 충돌은 원-원(반딧불·별가루·구름). 입자 효과는 퍼즐의 fx.js 재사용.
  • 목표 성능: 저가 안드로이드 60fps — 화면 밖 객체 제외, 배경은 미리 그린 띠 캔버스.

3고흐의 팔레트 — 색을 섞어 그림 되살리기

수수께끼형 퍼즐 · 미술 교육가장 빨리 만들 수 있음

“밤의 도둑이 그림의 색을 훔쳐 갔어요! 팔레트에서 물감을 섞어 똑같은 색을 만들면 그 부분이 다시 빛나요.”

목업: 색을 빼앗긴(흑백) 그림에서 지금 문제인 곳(점선)을 맞히면 그 부분이 원래 색으로 돌아온다. 아래 UI 는 아이가 실제로 그린 팔레트 모양 그대로 — 엄지 구멍까지.

게임 루프

문제 영역 보기→물감 방울 떨어뜨리기(몇 번씩)→섞어 보기 · 비슷한 정도 확인→「칠하기」→영역이 원래 색으로 ✨↻

규칙·학습 요소

  • 물감 5가지(흰·노랑·파랑·빨강·검정)를 방울 단위로 넣는다. 섞기는 물감처럼 섞이는 모델(빨강+노랑=주황, 파랑+노랑=초록이 되는 「감산 혼합」 근사).
  • 판정: 목표 색과의 색차 ΔE(CIEDE2000) ≤ 8 이면 정답, ≤ 15 면 「거의!」 + 방향 힌트(「더 노랗게」·「더 어둡게」).
  • 별점: 쓴 방울 수가 적을수록(=정확한 비율) ★★★. 「물감 아끼기」 미션.
  • 단계: ① 2가지 섞기(하늘의 파랑) ② 3가지(별 무리의 연두) ③ 명암(검정·흰색) ④ 그림 전체 되살리기(12영역).
  • 끝나면 「고흐는 왜 노란 별을 이렇게 칠했을까?」 같은 짧은 그림 이야기 카드(부모와 대화 거리).

기술 스케치

요소구현
문제 영역준비 단계에서 그림을 k-평균(Lab 색공간, k≈12)으로 나눈 뒤 작은 영역 병합 — 퍼즐의 prepare_image.py 확장. 영역별 대표 색 = 목표
섞기 모델RYB→RGB 근사 또는 Kubelka–Munk 2상수 근사(방울 수 = 농도). 결과를 Lab 으로 변환
판정CIEDE2000 ΔE, 힌트는 Lab 의 b*(노랑↔파랑)·L*(밝기) 차이 부호로 문장 선택
되살리기 연출흑백 그림 위에 영역 마스크로 컬러 그림을 원형으로 번지게(퍼즐의 원본 드러내기 응용)
UI팔레트 마스크(board-data.js)를 그대로 물감 판 모양으로 사용

5공통 기술 기반

  • 모두 정적 웹앱(서버 없음, 무료 호스팅, 오프라인) — 퍼즐과 같은 배포·검증 방식(Chromium·WebKit·Gecko 자동 시험).
  • 하나의 「별이 빛나는 밤 유니버스」 시작 화면에서 네 게임을 고르고, 각 게임에서 모은 별이 공동 「밤하늘 수집판」에 쌓이게 하면 재방문 동기가 생긴다.
  • 새 그림을 찍으면 같은 파이프라인으로 모든 게임이 그 그림으로 바뀌는 구조(아이의 다음 작품 대비).
