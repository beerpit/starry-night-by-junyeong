아이 그림이 곧 세계

세 게임 모두 아이의 팔레트 그림을 배경·무대·질감으로 그대로 쓴다. 퍼즐에서 만든 마스크 추출 파이프라인으로 하늘·사이프러스·마을·달을 레이어로 분리해 재사용.
🧒

초등 저학년 눈높이

읽기 부담이 적은 아이콘·음성, 실패해도 다시 하기 쉬운 구조, 폭력 없음. 막힐 때는 제한된 찬스(힌트) — 퍼즐과 같은 규칙으로 통일.
🌐

같은 기술 바탕

웹 표준(Canvas/WebGL, Pointer Events, Web Audio), 정적 호스팅·오프라인. 데스크톱·태블릿·휴대폰 모두. 처음 화면에 「게임 고르기」를 추가해 스티커·기록을 공유.

A별빛 탐정 — 사라진 일곱 별

수수께끼형 퍼즐 · 포인트 앤 클릭 어드벤처

어느 날 아침, 팔레트 그림 속 별 일곱 개가 감쪽같이 사라졌다! 꼬마 화가는 붓을 들고 그림 속으로 들어가, 마을 사람들의 수수께끼를 풀며 별을 하나씩 되찾는다.핵심 재미: 장면 구석구석 살피기 · 생각하는 수수께끼 · 별을 되찾을 때마다 밤하늘이 밝아지는 보상
대상7~10세 (보호자와 함께 5세~)
플레이 시간5장 · 약 60분
조작탭/클릭 하나

장 구성 — 그림 속 다섯 장소

장장소 (그림 속 위치)이야기되찾는 별
1🌲 검은 사이프러스 나무 (왼쪽)나무 속에 사는 부엉이 「밤톨」을 만나 안내자로 삼는다 (튜토리얼)★ 1
2⛪ 교회 첨탑 (아래 가운데)멈춘 종을 다시 울리자 첨탑 꼭대기에 걸린 별이 보인다★ 2
3🏠 불 켜진 마을 집들 (아래)창문 불빛 장난꾸러기 고양이가 별을 숨겼다★ 1
4🌀 소용돌이 하늘 (가운데)뒤엉킨 바람을 풀면 바람이 실어 간 별이 돌아온다★ 2
5🌙 초승달 (오른쪽 위)빛을 잃은 달을 노랗게 다시 칠하면 마지막 별이 깨어난다 — 엔딩: 일곱 별이 함께 반짝 (퍼즐의 축하 연출 재사용)★ 1

수수께끼 5종

이름유형규칙난이도 조절
숨은 부엉이관찰(숨은그림)검은 나무 붓 터치 속 눈 3쌍을 찾아 탭찾을 개수 2~5, 반짝 힌트
종소리 기억순서 기억(사이먼)종 4개가 울린 순서대로 탭 — 길이 3→6순서 길이, 재생 속도, 색 표시 유무
창문 불 끄기논리(라이트 아웃)창문을 누르면 자신과 이웃 창이 켜짐/꺼짐 반전 — 모두 끄기3×3 → 4×4, 최소 횟수 표시
바람 풀기공간(회전 타일)소용돌이 타일을 돌려 바람길을 별까지 이어 주기타일 수 9→16, 미리보기
달 색 만들기색 섞기(실험)물감 방울(파랑·노랑·흰색)을 섞어 목표 노랑을 만든다 — 실제 미술 지식 연결목표 색 허용 오차, 방울 수
힌트 부엉이 「밤톨」: 장마다 2번(찬스와 같은 제한). 1단계 「어디를 볼까?」 방향 → 2단계 해당 영역 반짝 → 3단계 정답 시연. 힌트를 안 쓰면 별 테두리가 금색(★★★ 평가와 같은 감각).

구현 메모

  • 핫스팟 = 다각형 + isPointInPath (퍼즐 엔진의 Path2D 재사용)
  • 장면 상태 기계: 탐색 → 대화 → 수수께끼 → 보상
  • 인벤토리 끌기 = 퍼즐 조각 끌기 코드 재사용
  • 음성 대사(선택): Web Speech API, 글자 크기 조절
  • 저장: 장·인벤토리·풀린 수수께끼 (localStorage)
  • 아트: 그림 레이어 분리 + 아이가 새로 그린 캐릭터(부엉이·고양이·꼬마 화가)를 사진 찍어 같은 파이프라인으로 투명 처리

B소용돌이 라이더

횡스크롤 아케이드 · 원 버튼

반딧불 「반짝이」가 소용돌이 바람을 타고 밤하늘을 가로지른다. 별가루를 모으고 사이프러스 가지를 피해, 달까지 날아가자!핵심 재미: 손가락 하나로 오르내리는 리듬감 · 소용돌이에 올라탈 때의 가속 · 콤보로 불어나는 별가루
대상6세~어른
한 판1~3분 (반복 도전)
조작누르고 있기 = 오르기
개발 규모MVP 2주 · 전체 4주

메커닉과 스테이지

🌀

소용돌이 기류

바람길(곡선 벡터장) 안에 들어가면 진행 방향으로 가속하고, 소용돌이 고리를 한 바퀴 돌면 「회오리 부스트」 — 그림의 붓 터치가 그대로 길이 된다.
✨

별가루 콤보

끊기지 않고 연달아 모으면 ×2→×4→×8. 부딪히면 콤보만 깨지고 게임은 계속(아이용 「반짝이 방패」 3칸).
🎁

파워업

🟡 노란 물감 = 별가루 자석, 🖌 붓 방패 = 한 번 무적, 🌠 별똥별 = 짧은 대시.
스테이지배경 (그림 레이어)새 요소길이
1. 마을 위마을 지붕·창문 불빛기본 오르내리기, 첨탑 피하기60초
2. 소용돌이 하늘흰 소용돌이·푸른 하늘바람길 가속, 회오리 부스트90초
3. 달 가까이별·달무리움직이는 구름 그림자, 별가루 비90초 + 달 착륙
∞ 끝없는 밤세 레이어 무작위 이어 붙이기점점 빨라짐, 최고 기록무한

시스템·기술

물리와 판정

  • 고정 시간 간격(1/60초) 물리 + 보간 그리기 → 기기 속도와 무관하게 같은 난이도
  • 반딧불: 원형 충돌, 장애물: 볼록 다각형(SAT)
  • 바람길: 곡선 위 최근접점 → 접선 방향 힘 F = k·(1 − d/폭)·t̂
  • 오브젝트 풀(별가루·입자 재사용)로 가비지 0

레벨·그래픽

  • 청크 템플릿(2~3초 분량) 30여 개를 난이도 가중 무작위로 이어 붙임
  • 시차 스크롤 4겹: 원경 하늘 0.2 · 소용돌이 0.4 · 마을 0.7 · 사이프러스 1.0
  • Canvas 2D 로 충분(필요하면 PixiJS 로 교체 가능하게 렌더 계층 분리)
  • 원 버튼: 터치·마우스·스페이스·게임패드 A
접근성: 「느린 바람」 모드(속도 70%), 「연습 모드」(부딪혀도 방패 무한), 색약 대비 별가루 테두리, 소리 신호로 장애물 예고.

C별빛 수호대

1인칭 슈팅 (비폭력 「빛 칠하기」)

구름 그림자 「먹구름이」들이 별빛을 먹어 마을이 깜깜해졌다. 빛 물감 붓을 든 별빛 수호대가 되어, 1인칭으로 마을을 거닐며 빛을 쏘아 별과 창문에 다시 불을 켜자!핵심 재미: 3D 로 걸어 들어간 아이의 그림 · 쏠 때마다 세상이 다시 칠해지는 손맛 · 무서움·폭력 없는 슈팅
대상8세~어른
플레이 시간4구역 · 약 40분
조작이동 + 조준 + 쏘기
개발 규모MVP 3주 · 전체 6주

메커닉과 레벨

🖌

빛 물감 붓

쏘면 노란 빛줄기. 먹구름이에 닿으면 터지지 않고 색이 칠해지며 작은 별가루로 흩어진다. 어두운 별·창문에 닿으면 불이 켜진다(점수).
🎨

세 가지 물감

🟡 노랑(기본) · 🔵 파랑(멀리 가는 줄기) · ⚪ 흰색(넓게 퍼짐). 큰 먹구름이는 약점 색이 있어 색 맞추기가 공략 — 미술 색 이론과 연결.
🛡

실패해도 무섭지 않게

먹구름이에 닿으면 화면이 잠깐 흐려지고 빛 물감이 줄 뿐. 체력·죽음 없음, 물감은 가로등 아래에서 다시 채움.
구역공간목표새 요소
1. 마을 광장좁은 골목·우물창문 8개 밝히기이동·조준·쏘기 익히기
2. 교회 언덕계단·첨탑종탑의 큰 별 밝히기높낮이, 파랑 물감
3. 사이프러스 숲검은 나무 미로숨은 반딧불 모으기어둠 속 소리 단서, 흰 물감
4. 달맞이 언덕탁 트인 들판큰 먹구름 소용돌이를 색으로 풀기보스: 약점 색 순서 맞추기 → 엔딩에 그림 전체가 다시 반짝

시스템·기술

3D 구성

  • Three.js(WebGL2) — 브라우저 공통, 정적 호스팅 유지
  • 하늘: 아이 그림을 반구형 하늘 돔 텍스처로(소용돌이·별이 머리 위에)
  • 집·나무: 로우폴리 + 아이 붓 터치를 잘라 만든 질감, 테두리선 셰이더로 그림 느낌
  • 판정: 레이캐스트(빛줄기) + 구 충돌(먹구름이)

조작·편의

  • 데스크톱: WASD + 마우스(Pointer Lock), 클릭 = 쏘기
  • 태블릿·휴대폰: 왼손 가상 조이스틱, 오른손 끌어 조준, 자동 쏘기 옵션, 자이로 조준(선택)
  • 멀미 줄이기: 시야각 75°, 화면 흔들림 없음, 15분마다 쉬기 알림
  • 저사양 모드: 그림자·입자·해상도 자동 조절(목표 60fps, 최소 30fps)
위험 요소: 셋 중 개발 규모·성능 부담이 가장 크다(휴대폰 GPU, 3D 에셋 제작). MVP 는 「마을 광장 1구역 + 노랑 물감」으로 재미를 먼저 검증할 것.
