2시작하기

어디서 열어요?

게임은 웹 브라우저에서 열리는 웹 게임이에요. 설치가 필요 없어요.

  • 인터넷 주소로: 게임을 올려 둔 주소(예: https://…/game/)를 브라우저로 열어요.
  • 파일로: 받은 폴더의 game/index.html 을 두 번 눌러 열어도 돼요. (인터넷 없이도 실행)

Android 휴대폰·태블릿Chrome, 삼성 인터넷두 손가락 확대, 진동 피드백
iPhone · iPad (iOS · iPadOS)Safari (다른 브라우저도 내부는 Safari 엔진)애플 펜슬로도 끌 수 있어요

홈 화면에 앱처럼 두기 (선택)

📱

iPad · iPhone (Safari)

  1. 게임 주소를 Safari 로 열기
  2. 공유 단추 ⬆︎ → 홈 화면에 추가
  3. 홈 화면의 「별밤 by Junyeong」 아이콘으로 전체 화면 실행
🤖

Android (Chrome · 삼성 인터넷)

  1. 게임 주소 열기
  2. 메뉴 ⋮ → 앱 설치 또는 홈 화면에 추가
  3. 한 번 열어 두면 인터넷 없이도 실행돼요
인터넷 주소로 한 번 열면 게임 전체가 기기에 저장돼서(오프라인 지원), 다음부터는 비행기 안에서도 할 수 있어요.

3처음 화면

  • 1그림 — 이번에 맞출 팔레트 그림이에요. 팔레트의 엄지 구멍까지 그대로 살렸어요.
  • 2그린 사람 — 화가 이름을 적어 두면 완성했을 때 「○○ 화가의 별이 빛나는 밤」이라고 불러 줘요. 이 기기에만 저장돼요.
  • 3이어 하기 — 하다 만 퍼즐이 있으면 나타나요. 단계·맞춘 조각 수·걸린 시간이 보여요.
  • 4난이도 고르기 — 6단계 카드. 해 본 단계에는 별점(★)과 최고 기록이 적혀요.
  • 5옵션 — 🔄 회전 모드 · 🖼 밑그림 · 🔊 소리. 고른 값은 기억돼요.
  • 6퍼즐 시작! — 고른 단계로 새 퍼즐을 만들어요. (카드를 두 번 눌러도 시작)
  • 7내 스티커 — 퍼즐을 하면서 모으는 7가지 스티커. 아직 못 받은 건 흐리게 보여요.

🔄

회전 모드

조각이 90°씩 돌아간 채로 섞여요. 조각을 톡 누르면 돌아가요. 더 어려워지지만 완성하면 「빙글빙글」 스티커!
🖼

밑그림

판 위에 흐린 그림이 깔려서 어디에 놓을지 알기 쉬워요. 게임 중에도 위쪽 단추로 켜고 끌 수 있어요.
🔊

소리

집을 때 「똑」, 맞으면 「딸깍·반짝」, 완성하면 팡파르가 나요. 조용히 해야 할 땐 꺼 두세요.

4게임 화면

  • 1🏠 처음 — 처음 화면으로. 하던 퍼즐은 자동 저장돼요.
  • 2상태 — 단계 · 🧩 맞춘 조각/전체 · ⏱ 걸린 시간. 아래 얇은 막대가 진행률이에요.
  • 3👁 원본 — 원래 그림을 작은 창으로 보여 줘요.
  • 4🖼 밑그림 — 판 위 흐린 그림 켜기/끄기.
  • 5🧹 정리 — 흩어진 조각을 줄 세워요. 테두리 조각이 판 가까이 먼저 와요.
  • 6🔍 맞춤 — 확대·이동한 화면을 한눈에 다시 보기.
  • 7🪄 찬스 — 남은 찬스 수가 동그라미에 보여요.
  • 8🔊 소리 — 효과음 켜기/끄기.
  • 9❓ 도움말 — 짧은 설명 창.
  • 10⛶ 전체 — 전체 화면 (지원하는 브라우저에서만 보여요).

손가락·마우스 쓰는 법

끌기

조각을 누른 채로 움직여요. 손을 떼면 놓여요.

톡 (회전 모드)

조각을 짧게 톡 누르면 90° 돌아가요. 마우스는 오른쪽 클릭도 돼요.

두 손가락 벌리기

화면이 커져요. 오므리면 작아져요. 마우스는 휠, 트랙패드는 두 손가락 벌리기.

빈 곳 끌기

조각이 없는 곳을 끌면 화면 전체가 움직여요. 🔍 맞춤으로 언제든 되돌려요.

5맞추는 규칙

🎯

제자리 근처면 딸깍!

판 위 원래 자리 가까이만 놓아도 저절로 쏙 들어가고 반짝여요. 들어간 조각은 고정돼서 더는 움직이지 않아요.
🤝

조각끼리 붙기

판 밖에서도 서로 이웃한 조각을 맞대면 붙어서 한 덩어리가 돼요. 덩어리는 같이 움직이고, 판에 놓으면 한꺼번에 들어가요.
🖌

테두리 조각

팔레트의 둥근 가장자리와 엄지 구멍, 오른쪽 홈에 닿는 조각은 모양이 특별해요. 이런 조각부터 맞추면 쉬워요.
🔄

회전 모드

돌아간 조각은 바른 방향이 될 때까지 톡톡 돌려야 판에 들어가요. 같은 방향끼리라면 판 밖에서 서로 붙을 수도 있어요.
아이에게 알려 주면 좋은 순서: ① 🧹 정리로 테두리 조각 모으기 → ② 팔레트 가장자리 → ③ 노란 별·달처럼 눈에 띄는 곳 → ④ 검은 사이프러스 나무 → ⑤ 남은 하늘.

6막혔을 때

🪄 찬스 — 횟수가 정해진 마법

  • 찬스를 누르면 조각 하나가 제자리로 날아가서 들어가요.
  • 먼저 조각을 톡 골라 두면(노란 테두리) 그 조각이 가요. 안 고르면 이미 맞춘 조각 옆에 갈 조각을 골라 줘요.
  • 찬스 수는 단계마다 정해져 있어요 (1단계 1번 ~ 6단계 8번). 다 쓰면 단추의 숫자가 회색 0 이 돼요.
  • 찬스를 안 쓰면 별 ★★★, 절반 이하로 쓰면 ★★, 더 쓰면 ★ 이에요.

8저장과 이어 하기

  • 조각을 놓을 때마다 자동 저장돼요. 🏠 를 누르거나, 창을 닫거나, 휴대폰을 꺼도 괜찮아요.
  • 다음에 열면 처음 화면에 ▶ 이어 하기 단추가 나와요. 조각 자리·덩어리·쓴 찬스·걸린 시간까지 그대로예요.
  • 다른 퍼즐을 새로 시작하면 이전 진행은 지워져요(시작 전에 한 번 물어봐요).
  • 시간은 게임 화면이 보일 때만 흘러요. 다른 앱으로 가면 멈춰요.
기록·스티커·진행 상황은 그 기기의 브라우저 안에만 저장돼요. 다른 기기와 자동으로 공유되지 않고, 어디로도 전송되지 않아요.

10자주 묻는 질문

소리가 안 나요.

① 도구 막대(또는 ⋯ 메뉴)의 🔊 가 켜져 있는지, ② 기기 볼륨, ③ iPhone·iPad 는 무음 스위치/집중 모드를 확인하세요. 브라우저는 화면을 한 번 누른 뒤부터 소리를 내 줘요.

조각이 너무 작아요 (휴대폰).

두 손가락으로 벌려 확대하고, 빈 곳을 끌어 옮기세요. 🔍 맞춤으로 언제든 전체를 다시 볼 수 있어요. 휴대폰에서는 3단계(21조각)까지가 편하고, 그 이상은 태블릿·컴퓨터를 추천해요.

조각을 놓았는데 안 들어가요.

제자리와 조금 더 가깝게 놓아 보세요. 회전 모드라면 방향이 맞는지도 확인하세요(톡 눌러 돌리기). 판 밖 조각끼리는 서로 이웃한 조각만 붙어요.

기록을 처음부터 다시 하고 싶어요.

브라우저 설정에서 이 사이트의 사이트 데이터(저장 공간) 삭제를 하면 기록·스티커·진행이 모두 지워져요.

인터넷이 끊겼어요.

한 번이라도 인터넷 주소로 열었던 기기라면 그대로 실행돼요. 파일(index.html)로 열 때는 원래 인터넷이 필요 없어요.

11부모님께

👨‍👩‍👧 함께 하는 방법

  • 아이가 그린 순서를 떠올리며 「하늘부터 그렸어? 나무부터 그렸어?」 이야기 나누기
  • 5단계(66조각)는 태블릿을 가운데 두고 둘이 번갈아 맞추기
  • 「찬스 없이」 스티커를 목표로 정해 보기

🛡 안심 정보

  • 광고·결제·회원가입·외부 전송이 없어요.
  • 이름(그린 사람)과 기록은 기기 안에만 저장돼요.
  • 앱 밖으로 창을 띄우거나 저절로 실행되지 않아요.
  • 깜빡임을 줄이는 「동작 줄이기」 설정을 켜 두면 축하 효과도 줄어들어요.
자세한 설계와 기술 설명은 「개발 문서」, 이 그림으로 만들 수 있는 다른 게임 아이디어는 「다른 게임 기획안」 문서에 있어요.
